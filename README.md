# 🚀 DocuMind Gemini - Document-Grounded Chatbot

మీరు అప్‌లోడ్ చేసిన ఫైల్ (PDF, Word, Text, CSV) లోని సమాచారానికి మాత్రమే ఖచ్చితమైన సమాధానాలు ఇచ్చే ఒక ఆధునిక **Gemini Document AI Chatbot**.

---

## 🌟 ముఖ్య ఫీచర్లు (Key Features)

1. **Strict Document Grounding (కఠినమైన డాక్యుమెంట్ గ్రౌండింగ్)**:
   - చాట్‌బాట్ సమాధానాలు **కేవలం మీరు అప్‌లోడ్ చేసిన ఫైల్ ఆధారంగా మాత్రమే** వస్తాయి.
   - ఒకవేళ అడిగిన ప్రశ్న సమాచారం ఫైల్‌లో లేకపోతే, అబద్ధాలు లేదా వెలుపలి సమాచారం చెప్పకుండా *"ఈ సమాచారం అప్‌లోడ్ చేసిన ఫైల్ లో అందుబాటులో లేదు"* అని స్పష్టంగా చెబుతుంది.
   - సమాధానంతో పాటు అది ఏ పేజీ లేదా సెక్షన్‌లో ఉందో (`[Page 9]`, `[Page 42]`) ఖచ్చితమైన రిఫరెన్స్ అందిస్తుంది.

2. **Gemini API Key Configuration**:
   - బ్రౌజర్ UI లోని **API Key** బటన్ క్లిక్ చేసి నేరుగా మీ Gemini API కీ ని సేవ్ చేసుకోవచ్చు.
   - లేదా ప్రాజెక్ట్ రూట్ లోని `.env` ఫైల్ లో `GEMINI_API_KEY=మీ_కీ` లాగా కాన్ఫిగర్ చేయవచ్చు.
   - **Test Connection** బటన్ తో మీ కీ సరిగ్గా పనిచేస్తుందో లేదో తక్షణమే చెక్ చేయవచ్చు.

3. **Multi-Format Document Upload**:
   - PDF (`.pdf`), Word Documents (`.docx`), Plain Text (`.txt`), Markdown (`.md`), CSV (`.csv`), JSON (`.json`) ఫైల్స్ సపోర్ట్ చేస్తుంది.
   - Drag & Drop లేదా File Picker ద్వారా 100MB వరకు ఫైల్స్ అప్‌లోడ్ చేయవచ్చు.
   - మీ వర్క్‌స్పేస్‌లో ఇప్పటికే ఉన్న `R25 C25 CSE Course Structure & Syllabus.pdf` (212 పేజీలు) ఆటోమేటిక్‌గా ఇండెక్స్ చేయబడింది.

4. **ప్రీమియం మోడ్రన్ డార్క్ UI (Rich Aesthetics)**:
   - గ్లాస్‌మార్ఫిజమ్ (Glassmorphism), వైబ్రెంట్ నియాన్ గ్లో యాక్సెంట్స్.
   - డాక్యుమెంట్ టెక్స్ట్ ఇన్‌స్పెక్టర్ (Preview Text & Live Search).
   - రెస్పాన్స్ కాపీ & రీడ్ అలౌడ్ (Text-to-Speech) బటన్స్.
   - తెలుగు మరియు ఇంగ్లీష్ లాంగ్వేజ్ సపోర్ట్.

## 🛠️ ఎలా రన్ చేయాలి? (How to Run)

సర్వర్ ఇప్పటికే రన్ అవుతోంది:
```bash
# ప్రాజెక్ట్ డైరెక్టరీలో సర్వర్ స్టార్ట్ చేయడానికి:
npm start
```
బ్రౌజర్‌లో క్రింది లింక్ ఓపెన్ చేయండి:
👉 **[http://localhost:3000](http://localhost:3000)**

---

## 🔑 Gemini API Key ఎలా పొందాలి?
1. [Google AI Studio](https://aistudio.google.com/app/apikey) కి వెళ్ళండి.
2. మీ Google ఖాతాతో లాగిన్ అయి **"Create API Key"** క్లిక్ చేయండి.
3. వచ్చిన కీ ని కాపీ చేసి:
   - యాప్ హెడర్‌లోని **"API Key"** బటన్ క్లిక్ చేసి పేస్ట్ చేసి **Save Key** నొక్కండి, లేదా
   - ప్రాజెక్ట్‌లోని `.env` ఫైల్‌లో `GEMINI_API_KEY=AIzaSy...` అని ఉంచండి.
